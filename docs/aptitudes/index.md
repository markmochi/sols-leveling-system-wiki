# Choose an Aptitude path

Every path offers a direct stat, four 5-rank passives, and a 10-rank **Awakening** capstone. The default 150-point budget lets a level-50 character max three paths, while smart builds plan around key passive gates and Awakening milestones.

## Quick comparison

| If you want... | Start with... | Why |
|---|---|---|
| Forgiving early survival | HP 8, then Vitality/DEF gates | The first eight HP ranks grant +6 health; early Fortitude passives begin at low ranks |
| A durable armored frontliner | Vitality + Fortitude | Healing, Second Wind, and Undying Surge pair naturally with Iron Skin Toughness and direct-hit mitigation |
| Fast exploration, faster attacks, or ranged kiting | Dexterity | Direct movement and attack speed, sprint efficiency, mobile handling, Return Marks, and Flow State Evasion |
| Potions, trade, faster Mastery growth, and debuff support | Intellect | Strong utility plus Field Study and Eidetic Memory's bonus Mastery EXP and target Expose |
| Better chest, fishing, and mob loot plus volatile combat | Fortune | Loot Luck can add a full table roll; Limit Breaker passively boosts Luck procs and unlocks boss wagers |
| Reliable weapon or unarmed specialization | Train a matching Mastery | Aptitudes shape stats and utility; STR, WEAPON, and RANGE Skill Trees handle combat-style scaling |

## How to read the tables

Gate pairs use `Aptitude / Player` order. For example, `20 / 10` means you need rank 20 in that Aptitude and Player Level 10 for that passive rank.

All values use the v1.1.0 defaults. Servers can enable Long Progression Mode to restore the original Player-Level and Aptitude-rank gates, customize Player-Level lists, or tune balance values via datapacks.

<div class="codex-callout"><strong>Passive ranks are free.</strong> Meeting a gate lets you claim the rank without spending another currency. Aptitude Points are spent only on the five main Aptitude ranks.</div>
